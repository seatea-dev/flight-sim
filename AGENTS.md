# Flight Simulator

This repository contains a lightweight browser-based 3D flight simulator.

## Priorities

- Smooth, responsive user experience.
- Visually polished but lightweight.
- Prefer simple solutions over unnecessary complexity.
- Keep the application primarily client-side.
- Avoid external APIs, databases, authentication, and backend infrastructure unless clearly justified.
- Optimize for maintainability and learning.
- Explain important architectural decisions before introducing significant complexity.
